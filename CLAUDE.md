# steelchart.org

Knife steel database: composition, hardness, 1-10 ratings, head-to-head comparisons and the knives that use
each steel. Python + Jinja2 generate a static site into `docs/`, which GitHub Pages serves.

## Layout

```
data/source/          compiled source datasets from the site plan (128 steels, 76 knives), 2026-10-14
tools/build_data.py   picks the Phase 0 set and writes data/*.json; knife specs are overridden with values
                      verified against the maker's page (KNIFE_VERIFIED, each with verified_url)
data/*.json           steels (30), knives (20), comparisons (50), brands, categories, equivalents
build.py              loads data, cross-references, generates prose from the data, renders docs/
svg.py                inline SVG charts: radar, composition bars, HRC gauge, diff chart, blade profile, scatter
templates/            Jinja2 templates (base.html, macros.html, one per page type, guides, legal pages)
static/               style.css, site.js (search, table sort/filter, theme toggle)
favicon/              generated by scripts/make_favicons.py (rsvg-convert + ImageMagick); build copies to root
```

## Running

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python tools/build_data.py   # only when data/source or the selection changes
.venv/bin/python build.py
python3 -m http.server 8766 -d docs    # local preview
```

## Data rules

- Every number on a page comes from data/. Prose on steel/compare/knife pages is generated from the data
  (build.py `steel_answer`, `steel_chemistry`, `verdict`, ...); keep generated claims general and true for
  the alloy in question (e.g. "harder than aluminium oxide" only for vanadium/tungsten carbides).
- Ratings have four axes (edge retention, toughness, corrosion resistance, ease of sharpening). The source
  data has no separate wear-resistance score; edge retention is the wear-resistance measure.
- Knife steels change: on 2026-10-14 the Manix 2 was MagnaMax, Bailout M4, Adamas/Link/0562CF MagnaCut,
  QSP Penguin QS130 D2. Re-verify against maker pages before adding or refreshing knives.
- Prices: the site shows the maker's list price (msrp_usd). The compiled street prices were dropped as unverifiable.
- Buck and Hogue block automated access; those two knives were checked on KnifeCenter listings.

## Site settings (top of build.py)

- `ADSENSE_PUB` is set; `GA_ID` and `AD_SLOTS` are placeholders (empty = no GA tags / auto ads only).
- Titles must be <= 60 chars (render() asserts). Descriptions are trimmed to 158 chars. Keep both unique.
- Comparison URLs are alphabetical by slug (`/compare/<a>-vs-<b>/`); the reverse URL is a noindex
  meta-refresh stub with a canonical link.
- Affiliate links: plain Blade HQ / Amazon search URLs with rel="nofollow sponsored" until AvantLink and
  Amazon Associates are approved. The affiliate disclosure page and footer note cover them.
